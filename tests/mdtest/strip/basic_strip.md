# Basic Strip

## Simple strip

```python
q = SQL[tuple[int]]("--sql\nSELECT 1::INTEGER")
# stripped: q = "--sql\nSELECT 1::INTEGER"
```

## Strip with multiple columns

```python
q = SQL[tuple[int, str]]("--sql\nSELECT id::INTEGER, name::TEXT FROM users")
# stripped: q = "--sql\nSELECT id::INTEGER, name::TEXT FROM users"
```

## Strip is idempotent

A plain --sql string without SQL[T] wrapper is unchanged:

```python
q = "--sql\nSELECT 1::INTEGER"
# stripped: q = "--sql\nSELECT 1::INTEGER"
```

## Non-SQL code is unchanged

```python
x = 42
# stripped: x = 42
```

## Manual SQL[T] wrapper is not stripped

A manually written `SQL[T]()` without `--sql` prefix is left untouched:

```python
q = SQL[int]("SELECT 1")
# stripped: q = SQL[int]("SELECT 1")
```

## Manual SQL[T] with custom query is not stripped

```python
q = SQL[tuple[int, str]]("SELECT id, name FROM users WHERE active")
# stripped: q = SQL[tuple[int, str]]("SELECT id, name FROM users WHERE active")
```

## Manual SQL[CustomType] without --sql is not stripped

```python
q = SQL[User]("SELECT id, name FROM users")
# stripped: q = SQL[User]("SELECT id, name FROM users")
```

## Manual SQL[CustomType] with --sql is stripped

Autogenerated wrappers are identified by `--sql` prefix, not by type parameter:

```python
q = SQL[User]("--sql\nSELECT id::INTEGER, name::TEXT FROM users")
# stripped: q = "--sql\nSELECT id::INTEGER, name::TEXT FROM users"
```

## Triple-quoted multiline wrapper is stripped

```python
q = SQL[tuple[int, str]]("""--sql
SELECT id::INTEGER, name::TEXT FROM users""")
# stripped: q = """--sql
# stripped: SELECT id::INTEGER, name::TEXT FROM users"""
```

## Triple-quoted multiline SQL[CustomType] with --sql is stripped

```python
q = SQL[User]("""--sql
SELECT id::INTEGER, name::TEXT FROM users""")
# stripped: q = """--sql
# stripped: SELECT id::INTEGER, name::TEXT FROM users"""
```

## Triple-quoted multiline SQL[CustomType] without --sql is not stripped

```python
q = SQL[User]("""SELECT id, name
FROM users
WHERE active""")
# stripped: q = SQL[User]("""SELECT id, name
# stripped: FROM users
# stripped: WHERE active""")
```

## Wrapper split across lines by a formatter is stripped

```python
q = SQL[tuple[int]](
    "--sql\nSELECT id::INTEGER FROM users"
)
# stripped: q = "--sql\nSELECT id::INTEGER FROM users"
```

## Wrapper-like text in a comment is not stripped

The row type never spans lines, so a match can't start in the comment.

```python
from sqlty import SQL
# see SQL[T] docs
q = SQL[tuple[int]]("--sql\nSELECT 1::INTEGER")
# stripped: from sqlty import SQL
# stripped: # see SQL[T] docs
# stripped: q = "--sql\nSELECT 1::INTEGER"
```

## Formatter trailing comma

```python
from sqlty import SQL

q = SQL[tuple[int]](
    "--sql\nSELECT 1::INTEGER",
)
# stripped: q = "--sql\nSELECT 1::INTEGER"
```
